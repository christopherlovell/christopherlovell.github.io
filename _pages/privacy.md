This page covers the personal automation tools I run, including a Google OAuth client
used with the [gog](https://gogcli.sh) command-line tool.

- **Who uses it:** only me, Chris Lovell, on my own Google accounts. It is not offered to anyone else.
- **What it accesses:** read-only access to my own Google Calendar, used to find talks and seminars
  so I can keep the talks list on this website up to date.
- **Where data goes:** calendar data is processed on my own computer. It is not sold, shared
  with third parties, or used for advertising.
- **Storage:** OAuth tokens are stored encrypted on my own computer. Access can be revoked at any time
  from [Google Account permissions](https://myaccount.google.com/permissions).

This website itself does not collect personal data beyond standard hosting logs.
