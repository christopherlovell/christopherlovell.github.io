details: >-
  The Synthesizer project is an open source suite of tools for forward and inverse modelling of astrophysical observables. At its core is a fast, modular Python package for generating synthetic observables from simulations and models, alongside tools for grid generation, SED fitting with simulation-based inference, and mock catalogue noise modelling. I co-lead the development of Synthesizer and its wider ecosystem.
